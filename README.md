# 4Story Millionaire — GitHub Pages

**Полностью готовая версия для GitHub Pages.** Главный файл: `index.html`. Никаких сборок и npm не требуется.

## Публикация через сайт GitHub

1. Откройте [GitHub](https://github.com/) и войдите в аккаунт. Создайте **публичный** репозиторий, например `4story-millionaire`, либо откройте уже существующий.
2. **Распакуйте ZIP на компьютере. НЕ загружайте только ZIP-файл в репозиторий!**
3. В репозитории нажмите **Add file → Upload files**. Перетащите **всё содержимое** распакованной папки в корень репозитория: `index.html`, папки `css`, `js`, `assets`, а также `.nojekyll`. Подтвердите **Commit changes**. Файл `.nojekyll` может быть скрытым в Windows; если не видно, включите показ скрытых файлов.
4. Откройте **Settings → Pages**. В секции **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/(root)**; нажмите **Save**.
5. После публикации откройте адрес вида `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/4story-millionaire/` (имя репозитория и пользователя будут вашими). GitHub покажет точную ссылку в разделе **Settings → Pages → Visit site**.

> Если в репозитории уже есть сайт, замените `index.html`, `css`, `js`, `assets`, не удаляя ваши сторонние файлы. Не размещайте папку `4Story_Millionaire_GitHub_Pages` внутри корня — **содержимое папки** должно лежать прямо в корне (чтобы `index.html` был на верхнем уровне).

## Содержимое

- `index.html` — главная страница, 5 языков, английский по умолчанию
- `css/style.css` — все стили ПК и телефона
- `js/game.js` — игровые режимы, 36 стандартных вопросов, 6 пользовательских слотов и редактор
- `assets/images/*` — фон и логотип
- `assets/audio/*` — 11 треков и эффектов
- `.nojekyll` — отключает обработку сайта Jekyll на GitHub Pages

## Важные замечания

- Пользовательские игры сохраняются в **localStorage браузера**. Если перейти с HTML-файла или с другого домена, черновики автоматически не появятся. Сохраните свои игры через **Export JSON** и импортируйте на новом сайте.
- **HTML for friends** загружает стили и звуки из текущего сайта при экспорте, поэтому для его создания нужен интернет. Скачанный HTML будет самостоятельным и откроется без подключения.
- Для просмотра YouTube-видео внутри игры нужен интернет.
- Музыкальные записи могут охраняться авторскими правами. Убедитесь, что у вас есть право публично размещать аудиофайлы в репозитории и на сайте.
- GitHub Pages — статический хостинг: вопросы посетителей сохраняются только в их браузерах. Между друзьями игры передаются через JSON либо самостоятельно экспортированный HTML, а не через облачный аккаунт.

## Обновления

Поменяйте файлы в репозитории и сохраните коммит в ветку `main` — GitHub Pages опубликует новую версию по прежней ссылке. Если видно старую версию, обновите страницу с очисткой кеша (`Ctrl+F5`).
